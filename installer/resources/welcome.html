RPM - Resolve Project Manager

Cet assistant installe le plugin dans DaVinci Resolve Studio.

  1. Ferme DaVinci Resolve avant de continuer.
  2. Clique sur Continuer, puis Installer. Ton mot de passe Mac te sera demandé.
  3. Rouvre Resolve et lance le plugin depuis Workspace → Workflow Integrations.

Si une version précédente est installée, elle est remplacée et une sauvegarde est conservée.
