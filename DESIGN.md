# Design

## Surface

RPM - Resolve Project Manager is a temporary four-step setup assistant opened from Resolve Studio's Workflow Integrations menu. It closes after setup so the editor can continue in Resolve.

## Approved visual direction

The direction is now DaVinci Resolve's own interface: dark charcoal panels, fine grey rules, compact controls with small radii, and an orange accent for the active step and primary action. Keep the layout and content focused on creating a Resolve project; do not add unrelated decoration.

## Interface rules

- Use dark charcoal surfaces, thin grey separators, readable system sans-serif text, and orange for active steps and the primary action.
- Use medium-weight headings in sentence case and small-radius controls. Avoid heavy shadows; separate groups with borders.
- Keep media classification dense but scannable. Use editable controls for category, camera brand, model, and shooting date.
- Keep errors and metadata uncertainty beside the affected step. Do not imply a failed metadata read means Resolve cannot decode the file.
- Make optional timeline setup clear. Present proxy preparation as a handoff to Blackmagic Proxy Generator; do not suggest the plugin generates proxies itself.
- Use four steps: Projet, Sources, Organisation, Terminé. End with a close action that opens Resolve's Edit page.
- Do not add a persistent project dashboard to V1.
